🧠 先懂原理：码量为什么改变范围

范围的骨架(高牌)几乎不变,真正随码量伸缩的是投机性同花牌。记住三条原理,你就能推导而不是死背:

① 隐含赔率 (码越深越值钱)同花连张、小对子靠"偶尔中坚果赢一大笔"盈利。筹码越深,中了能赢越多 → 深码加同花投机牌。
② 反隐含赔率 (码越深越危险)被支配的 offsuit 牌 (KJo/QJo/AJo) 中了顶对常被更大牌打爆。深码反而要降低这些牌的频率。
③ 位置杠杆 (越靠后越宽)后位永远多一手信息。所以 UTG 只开 ~16%,而 BTN 能开 ~45%。位置决定宽度,码量决定同花投机牌的多少。

⚠️ 注意:RFI(开池)范围受码量影响其实较小;码量影响最大的是 3-bet4-bet冷跟注全下阈值。本表聚焦最该先背熟的开池范围。

🎨 三色记忆法（核心）

别背 15 张表。每个位置只背 1 张三色表,码量决定你"开到第几种颜色":

绿 = 核心(50bb 起就开) 黄 = 标准加牌(100bb 加上) 蓝 = 深码加牌(300bb 再加上) 灰 = 弃牌
码量你开的颜色一句话
50bb (浅) 只开绿砍掉投机牌,只留硬高牌 + 主力同花连张
100bb (标准) 绿 + 黄标准 GTO 范围,大多数桌的默认
300bb (深) 绿 + 黄 + 蓝加同花投机牌博隐含赔率;同时降低 offsuit 被支配牌的频率

行=高张,列=低张;右上三角=同花(s),左下三角=非同花(o),对角线=对子。点不了,纯背图。

⚡ 速记口诀表

位置50/100/300bb 开池%记忆抓手
UTG 枪口13 / 16 / 18%最紧。只开硬牌:对子全开、AJ⁺/KQ、同花连张只到 T9s。黄=补齐同花A+KJo;蓝=87s/76s/65s 等同花连张
MP 中位14 / 19 / 21%比 UTG 略宽。加 KJo/QJo、98s、更多小同花K/Q。蓝=小同花连张 + ATo
CO 关煞19 / 24 / 28%打开了。全部对子 + 全部同花A、宽同花K、同花连张到 65s、offsuit broadway 入场
BTN 按钮30 / 42 / 50%最宽,近一半牌。几乎所有同花 + 大量 offsuit (A2o⁺/K9o⁺/Q9o⁺)。蓝=同花单/双张缺口
SB 小盲23 / 31 / 37%只对抗 BB 但要 OOP,采加注或弃牌。宽度近 CO/BTN 之间,offsuit 略收

※ 百分比为 6-max 简化示意值(不同 solver / 抽水设定会有 ±2% 出入),重在记住相对宽窄与三色结构,而非精确到个位。

📐 三档码量的调整规则（背完图再看这个就通了）

🔻 50bb（浅码）：砍投机、留高牌
  • 削掉最依赖隐含赔率的牌:小同花连张/缺口张 (65s、54s、小 Kxs/Qxs)。
  • 小对子价值下降(中set赢不到一整叠),靠后位仍开,前位可适当收。
  • 高牌、offsuit broadway 相对保值,因为靠摊牌价值与弃牌率盈利。
  • 3-bet 更极化/直接全下,因为筹码浅、更容易一把定胜负。
⚖️ 100bb（标准）：默认基准
  • 就是大多数图表与训练软件的默认范围 = 绿 + 黄。
  • 先把这一档背到不用思考,它是其他两档的"原点"。
🔺 300bb（深码）：加同花、减被支配 offsuit
  • 加宽同花投机牌(蓝色):同花连张、同花缺口张、弱同花 A/K —— 隐含赔率巨大,中坚果同花/顺子能赢整叠。
  • 降低 KJo / QJo / AJo 这类被支配 offsuit 的频率(反隐含赔率,中顶对易被打爆)。
  • 位置价值放大:IP(BTN/CO)更敢拓宽;OOP(SB/UTG)反而要更克制。
  • 多用冷跟注/慢打,3-bet 更线性、更谨慎,避免浅范围被深筹码惩罚。

🧭 建议的背诵顺序

  • 第一步:先背 100bb BTN 和 100bb UTG —— 一最宽一最紧,建立两端锚点。
  • 第二步:补 CO / MP / SB,它们都落在两个锚点之间。
  • 第三步:对每个位置,记住"砍黄=50bb,加蓝=300bb"两个动作即可,不用单独背。
  • 第四步:再去学 3-bet / 防守 / 4-bet 范围 —— 那才是码量影响真正大的地方。
